# CRESYVA — Template Boutique V9

## Ce qui a été ajouté

- Nouveau template sectoriel `retail` / boutique.
- Hero éditorial plein écran avec image du tenant, CTA et preuves de confiance.
- Navigation visuelle par catégories avec les vraies images du catalogue.
- Grille « sélection du moment » avec prix, promotions et badges issus des données réelles.
- Bloc promotions distinct, uniquement si de vraies promotions existent.
- Bloc éditorial de marque utilisant les médias réels du tenant.
- Témoignages réels si disponibles.
- CTA final vers le catalogue.
- Version responsive mobile/tablette.
- Header de la boutique en overlay sur le hero.
- Chargement spécifique des données nécessaires au template retail.
- Palette par défaut retail réorientée vers un univers boutique éditorial : noir encre / ivoire / camel.

## Données

Aucun produit, prix, statistique, avis ou promotion fictifs n'est créé. Les cartes et chiffres affichés proviennent des données publiques du tenant.

## Compatibilité

Le template conserve les routes publiques existantes et utilise les mêmes produits/catégories/témoignages que le catalogue public. Le reset de vitrine revient à ce template comme design retail par défaut.

## Validation

Le projet ne contient pas `node_modules` dans cet environnement. `tsc --noEmit` a donc produit les erreurs attendues liées aux types Next/React absents ; aucun nouveau message de syntaxe TypeScript/JSX spécifique n'a été détecté au-delà de ce bruit d'environnement.
