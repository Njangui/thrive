# CRESYVA — V15 Sector Polish

## Scope
Polish pass over all five dedicated tenant home templates plus the generic fallback:
- Immobilier
- Restaurant
- Boutique / retail
- Beauté & bien-être
- Services professionnels
- Générique

## Improvements
- Sector-specific demo imagery instead of reusing generic SaaS cards.
- Richer empty-tenant states while keeping demo content visibly marked as examples.
- More reference-oriented hero proportions, section rhythm, cards, hover states and mobile layouts.
- Real-estate demo property types now use dedicated visuals.
- Restaurant menu categories now use dedicated food/drink visuals.
- Retail now has dedicated editorial hero/story/category/product visuals.
- Beauty services/gallery use beauty-specific visuals.
- Professional services use professional-specific visuals.
- Removed several unsupported marketing promises from sector blueprint subtitles.
- Real-estate demo statistics are explicitly marked as examples when no real stats exist.
- Verified all `/images/demo/*` references resolve to existing assets.

## Data integrity
Real tenant data remains preferred whenever available. Demo content is only a fallback for empty tenant states and is labeled as example content.
