# C4 — Stockage médias R2 (étape 1)

## Décisions
- Adaptateur S3-compatible `R2StorageAdapter` derrière le port `StorageProvider` existant ; sélection par `STORAGE_PROVIDER` (`supabase` par défaut, `r2`).
- Signature SigV4 maison (`sigv4.ts`, `node:crypto` + `fetch`) plutôt que `@aws-sdk/client-s3` : aucune dépendance ajoutée. Vérifiée contre le vecteur de test officiel AWS.
- Chemins préfixés par l'organisation (comme Supabase) + refus des segments `.` / `..`. Pas de nouvelle migration à cette étape.
- `if-none-match: *` à l'upload pour reproduire `upsert: false` — **à vérifier** sur un vrai bucket R2.

## Limites
- Pas encore : variantes d'images, outil de migration des médias existants, URLs présignées. Prochaine PR.
- L'isolation tenant repose, comme avant, sur le préfixe de chemin + `requireMembership` en amont (service-role).
